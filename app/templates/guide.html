Professors CSV quick notes

Upload professors_complete_verified.csv on Contacts. MailPilot detects the China schema and fills the options that looked “missing”:

  • country / timezone — source file had no country column → set to China / Asia/Shanghai
  • region type — defaults to china (China CSC template)
  • groups — professor, china, botany plus usama_batch / faizan_batch
  • English name — prefers professor_name_en; missing EN tagged needs_english_name
  • not stated title/research cleaned; empty research tagged needs_research

CLI: python scripts/prepare_professors_csv.py path/to.csv -o samples/professors_mailpilot_ready.csv
